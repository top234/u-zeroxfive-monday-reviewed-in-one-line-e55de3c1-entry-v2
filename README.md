A one-line review of Monday, written as if Monday itself were the product being rated: the calendar invited me to a meeting with myself, and I still showed up late. One star — the week has not even started and it is already running behind schedule on its own appointment.

## Run it

```sh
node main.ts
```

This writes the review line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set), validates that it is a single line of 1–200 characters, and reads it back to confirm it is byte-identical.
